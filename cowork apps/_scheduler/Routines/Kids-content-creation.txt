--- STEP 3: DESIGN GUARDRAILS ---
  - Target audience: young children ages 4-8, with parent nearby.
  - UI must be extremely simple: huge buttons, bright cheerful colors,
    large readable fonts (no cursive), minimal text on screen at once.
  - Instructions must be understood without reading — use icons, arrows,
    and clear visual cues; include short audio hints via Web Audio API
    if helpful (chime when correct, happy sound on completion).
  - NO typing required if possible — prefer tap/click/drag interactions.
    If typing IS needed, keep it to one word or name maximum.
  - Celebrate everything — every action gets a positive response
    (sparkle effect, happy sound, encouraging word). Never negative feedback.
  - Output must be something a child can show a parent — displayable,
    printable, or downloadable as an image (Canvas toDataURL).
  - No timers that stress, no fail states, no score that goes down.
  - All content completely safe: no violence, no adult themes,
    no external links, no text entry that sends data anywhere.
  - No ads, no external links, no data collection.
